## Phase Goal

**As an** operator, **I want to** add a node host to the inventory and run one playbook, **so that** the node is registered in the Panel through the API without the UI, accepts clients over VLESS Reality on 443 and looks like an ordinary website with a real certificate of its own domain to everyone else.

This plan's slice: **after one run the node is registered in the Panel, its inbound is in the declared squads, and the playbook waits until the Panel reports it connected.**

Purpose: API-02 (node + squads), API-03 (no duplicates), API-04 (wait for connected), API-01 (check/diff).
Output: two modules, unit tests, register steps, VM assertions.
</objective>
