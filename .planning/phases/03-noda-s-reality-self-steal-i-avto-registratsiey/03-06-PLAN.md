## Phase Goal

**As an** operator, **I want to** add a node host to the inventory and run one playbook, **so that** the node is registered in the Panel through the API without the UI, accepts clients over VLESS Reality on 443 and looks like an ordinary website with a real certificate of its own domain to everyone else.

This plan's slice: **in an enforcing VM next to a real Panel VM, the node's own domain gets a real ACME certificate on the loopback entrypoint, and that entrypoint is unreachable from another host.**
