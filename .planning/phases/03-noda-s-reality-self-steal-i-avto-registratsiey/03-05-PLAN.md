## Phase Goal

**As an** operator, **I want to** add a node host to the inventory and run one playbook, **so that** the node is registered in the Panel through the API without the UI, accepts clients over VLESS Reality on 443 and looks like an ordinary website with a real certificate of its own domain to everyone else.

This plan's slice: **443 opens only after the node's certificate is proven on loopback, and the node API port answers only the Panel, on all three EL10 platforms.**

Purpose: NODE-02, STEAL-05 (and STEAL-01 proof in the VM: the real LE-style certificate on the loopback entrypoint).
Output: `gate.yml`, `firewall.yml`, verifier extension, matrix.
