## Phase Goal

**As an** operator, **I want to** deploy the Panel host with one command, **so that** Remnawave Panel is reachable over HTTPS on its own domain behind a cookie/secret-path gate, the first admin, the API token and the subscription page are set up automatically, and a re-run changes nothing and never touches the secrets.

This plan's slice: **the Remnawave backend runs on the Panel host behind loopback with secrets that are generated once, kept on the host and never leak or rotate silently.**

<objective>
Add the Panel stack (Postgres 18.4, Valkey 9, backend 3.4.11) as rw-panel Quadlet units with a generate-once secrets file on the Panel host, plus the DOC-04 guards (placeholder asserts, divergence/loss refusal, static no_log check).

Purpose: PANEL-01, PANEL-02, DOC-04; the secrets file location/format is the D-07 interface (costly) for Plans 03-05, Phase 3 and Phase 5 backups.
Output: `roles/panel/tasks/{secrets,stack}.yml`, unit/env templates, `verify_panel.yml`, `scripts/check_no_log.py`, container-tier negative cases.
</objective>
