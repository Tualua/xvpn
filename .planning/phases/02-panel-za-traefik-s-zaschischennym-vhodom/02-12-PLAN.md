<objective>
Close UAT gap 02-UAT-G1: after switching xvpn_edge_acme_ca (staging -> production, or any CA change) a re-run of
panel.yml must serve certificates of the newly selected CA. Root cause: the le resolver keeps one storage file for every
CA and Traefik reuses a stored certificate until 30 days before expiry, whatever caServer says. Fix: one storage file
per CA, so a switch starts from an empty store and a switch back reuses the earlier store.

Per D-13 (persistent stores, 0600) with per-CA file names superseding the single acme.json name.

Purpose: the operator's documented path "test on staging, then switch to production" works by itself, without root
access to the rw-edge account (which has /sbin/nologin) and without deleting files by hand.
Output: per-CA storage in the edge role, verifiers pointed at the active store, a container-tier case, a VM-tier CA
switch proof, README guidance.
</objective>
