## Phase Goal

**As an** operator, **I want to** deploy the Panel host with one command, **so that** Remnawave Panel is reachable over HTTPS on its own domain behind a cookie/secret-path gate, the first admin, the API token and the subscription page are set up automatically, and a re-run changes nothing and never touches the secrets.

This plan's slice: **every push re-proves the admin gate on the production templates and the pinned Traefik image in minutes, so a router regression cannot reach main unnoticed; and no push can commit a real secret value.**

Turn the gate spike (RESEARCH "Executed spikes") into a CI regression: render the production edge/panel templates, run the pinned Traefik image against Pebble and stub backends on the runner, execute the verify_gate matrix by case id, and run it on every push.

Add the DOC-04 repository secret scan to the quality gate, so the "real secrets are not stored in the repository" clause is checked on every push, not only asserted in prose.

Purpose: PANEL-06 regression protection (HIGH RISK item), QA-05 for the new workflow, DOC-04 second clause.

`.gitleaks.toml` (repository root, TOML): `title = "xvpn.remnawave"`; `[extend]` with `useDefault = true` (upstream default ruleset, which already carries the `jwt`, `private-key` and generic rules). Two `[[rules]]`:

One `[[rules.allowlists]]` with `regexTarget = "secret"` and exactly these regexes: `^\{\{` (Jinja reference), `^<` (`<from vault>` style placeholders), `^(?i)change_?me`, and the lowercase FHS path `^/(?:var|etc|run|srv|opt|usr|home|tmp)(?:/[a-z0-9._-]+)+$` (real paths such as `/var/lib/xvpn/rw-panel/secrets/panel-secrets.yml` under `xvpn_panel_secrets_file`; a base64 value has upper-case letters and does not start with one of these roots, so it stays flagged).
2. id `xvpn-url-userinfo`: regex `\b[a-zA-Z][a-zA-Z0-9+.-]*://[^\s:/@'"]+:([^\s/@'"]{8,})@`, `secretGroup = 1`, `keywords = ["://"]`, rule allowlist (`regexTarget = "secret"`) `^\{\{`, `^<`, `^\$\{`, `^(?i)change_?me`.
One global `[[allowlists]]`, description "marked non-secret gate test fixtures", `condition = "AND"`, `targetRules = ["xvpn-secret-key"]` (the default rules, JWT and PEM included, are never allow-listed), `paths` = `^scripts/gate/[^/]+$` and `^extensions/molecule/.+` (anchored: gitleaks runs with the scan root as cwd and target `.`, so reported paths are repo-relative and `inventory/extensions/molecule/x.yml` does not match), `regexTarget = "line"`, `regexes` = `# xvpn-test-fixture: non-secret\s*$`. No `.gitleaksignore`, no baseline.
