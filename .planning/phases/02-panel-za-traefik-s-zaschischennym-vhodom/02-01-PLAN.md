## Phase Goal

**As an** operator, **I want to** deploy the Panel host with one command, **so that** Remnawave Panel is reachable over HTTPS on its own domain behind a cookie/secret-path gate, the first admin, the API token and the subscription page are set up automatically, and a re-run changes nothing and never touches the secrets.

This plan's slice: **the operator's Panel domain answers over HTTPS with a real ACME certificate (Pebble in CI), unknown names get nothing, and Traefik logs the real client IP.**

<objective>
Create the reusable `edge` role (Traefik v3.7.20 + decoy nginx, rootless Quadlet under rw-edge, ACME HTTP-01, file-provider route interface), a minimal `panel` role that publishes the Panel-domain decoy route through that interface, `playbooks/panel.yml` + `playbooks/site.yml`, and switch both Molecule tiers from the Phase 1 fixture to the real playbook with Pebble in the VM tier.

Purpose: EDGE-01..03 and QA-05; the D-16 route interface that Plans 02-05 and Phase 3 build on.
Output: `roles/edge/**`, `roles/panel/**` (routes only), playbooks, VM Pebble prepare, `verify_edge.yml`, container-tier wiring, QA-05 static guard.
</objective>
