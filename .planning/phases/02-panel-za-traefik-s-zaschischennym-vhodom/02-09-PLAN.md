## Phase Goal

**As an** operator, **I want to** deploy the Panel host with one command, **so that** Remnawave Panel is reachable over HTTPS on its own domain behind a cookie/secret-path gate, the first admin, the API token and the subscription page are set up automatically, and a re-run changes nothing and never touches the secrets.

This plan's slice: **clients open the subscription page on its own domain over HTTPS, and it pulls their data from the Panel with the bootstrap token with no manual steps.**

Prove SUB-02 with an authenticated probe and a wrong-token negative control.

Purpose: SUB-01, SUB-02; completes the phase goal and its public documentation.
Output: `roles/panel/tasks/subpage.yml`, three templates, `verify_subpage.yml`, side_effect negative control, container toggle case, README Panel section.
