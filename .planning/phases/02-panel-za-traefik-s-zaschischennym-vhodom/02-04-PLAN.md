## Phase Goal

**As an** operator, **I want to** deploy the Panel host with one command, **so that** Remnawave Panel is reachable over HTTPS on its own domain behind a cookie/secret-path gate, the first admin, the API token and the subscription page are set up automatically, and a re-run changes nothing and never touches the secrets.

This plan's slice: **the operator opens the secret admin URL, gets the cookie and the Panel UI over HTTPS; everyone else sees only a neutral site, while the API stays usable with a token.**

<objective>
Publish the Panel through Traefik behind the pure-Traefik cookie/secret-path gate (RESEARCH Pattern 1, verified by spike), write the admin URL file, amend the PANEL-06 wording (D-02), prove the full positive and negative matrix in the VM tier and keep it as a CI regression on the real templates.

Purpose: PANEL-05, PANEL-06 (HIGH RISK item of the phase; the spike has already passed, this plan makes it a regression test).
Output: gate routers in `panel-routes.yml.j2`, `admin-url` file, `verify_gate.yml`, `scripts/gate/{run.sh,render.yml}`, `.github/workflows/gate.yml`, amended requirement text.
</objective>
