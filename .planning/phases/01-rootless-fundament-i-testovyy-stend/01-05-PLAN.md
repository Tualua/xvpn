## Phase Goal

**As an** operator, **I want to** run one playbook on a clean Rocky/Alma 10 host, **so that** I get a verified rootless host where a dedicated user with linger runs a Quadlet service on port 80 that survives reboot under SELinux enforcing with zero AVCs, all checked automatically by Molecule and CI linters.

This plan's slice: **a non-EL10 or non-enforcing host is stopped in a read-only first play, and the operator can run that check on its own.**

<objective>
Create role `preflight` with the OS + SELinux checks (Plan 06 adds Podman, ports and DNS to the same aggregation), make it the read-only first play of `playbooks/foundation.yml`, and add the standalone `playbooks/preflight.yml` entry point (D-09: preflight "запускается сама по себе").

Purpose: D-06, D-09, FND-01 subset.
Output: role `preflight` (OS/SELinux), two-play `foundation.yml`, `playbooks/preflight.yml`.
</objective>
