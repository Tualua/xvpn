## Phase Goal

**As an** operator, **I want to** run one playbook on a clean Rocky/Alma 10 host, **so that** I get a verified rootless host where a dedicated user with linger runs a Quadlet service on port 80 that survives reboot under SELinux enforcing with zero AVCs, all checked automatically by Molecule and CI linters.

This plan's slice: **the operator's host keeps SELinux enforcing and its SSH access, and the firewall exposes exactly the ports the collection's services need — nothing internal.**

Output: `roles/common/**`, updated `playbooks/foundation.yml`, container converge/verify, `extensions/molecule/shared/verify_common.yml`.
</objective>
