## Phase Goal

**As an** operator, **I want to** run one playbook on a clean Rocky/Alma 10 host, **so that** I get a verified rootless host where a dedicated user with linger runs a Quadlet service on port 80 that survives reboot under SELinux enforcing with zero AVCs, all checked automatically by Molecule and CI linters.

This plan's slice: **the operator (and every later phase) can prove on real enforcing EL10 VMs that the rootless :80 service survives a reboot with zero AVCs — one command locally, automatically on PRs and nightly.**

<objective>
Run the VM scenario from Plan 11 in GitHub Actions with a KVM gate, spike the Vagrant + libvirt recipe on hosted runners, apply the pre-decided fallback if needed, and drive both legs to green (QA-03); document the testing tiers in the README.

Output: `.github/workflows/molecule-vm.yml`, README `## Testing`, green VM runs (or the documented D-16 local fallback); `create.yml`/`destroy.yml` only under decision rule 2.

Scope note (task count, checker iteration 2): this plan has 4 task blocks, one above the 3-task guideline, kept deliberately. Tasks 3 (`checkpoint:decision`) and 4 (`checkpoint:human-action`) are conditional and carry no implementation: they only present evidence and options when Task 2 hits an AVC, a failing dontaudit positive control, an exhausted repair budget (Task 3) or the D-16 local-run fallback (Task 4); otherwise SUMMARY records "Task 3: not triggered" / "Task 4: not triggered". They cannot move to a separate plan because they resume Task 2 in place, and the VM spike of Task 2 cannot be separated from the workflow of Task 1 that it runs. Implementation work is Tasks 1 and 2. Expected overrun: the `estimate` (50000 tokens, confidence low, no calibration samples) covers one clean VM round; each VM fix round adds roughly 10000-15000 tokens (longer logs, two legs), and decision rule 2 (delegated GenericCloud fallback: new create.yml/destroy.yml) adds about 20000 more, so the worst bounded case is about 100000 tokens. Past the 2-rounds-per-distinct-failure budget the loop does not continue: it ends at the Task 3 handoff, which bounds the overrun.
</objective>
